Cognitive Complexity measures how hard a function is to understand. Functions with a high score are hard to read, test and change safely.

The score, following SonarSource's Cognitive Complexity definition, adds:

  • +1 for each if, else if, else, switch, loop, catch and ? : operator;
  • +1 more for each level of nesting those structures are inside (except else and else if);
  • +1 for each sequence of and / or operators in a condition.

Blocks (\ x -> ...) increase the nesting level of the code they contain.

How to fix it

Extract nested blocks into well-named functions, return early instead of nesting, and replace long condition chains with lookups or polymorphism.

Noncompliant code example

function premium(policy : Policy) : BigDecimal {
  var total = 0bd
  for (vehicle in policy.Vehicles) {            // +1
    if (vehicle.Active) {                       // +2 (nesting 1)
      for (driver in vehicle.Drivers) {         // +3 (nesting 2)
        if (driver.Age < 25 and driver.Claims > 0) {   // +4 (nesting 3) +1 (and)
          total += surcharge(driver)
        }
      }
    }
  }
  return total
}

Compliant solution

function premium(policy : Policy) : BigDecimal {
  var total = 0bd
  for (vehicle in policy.Vehicles.where(\ v -> v.Active)) {   // +1
    total += driverSurcharges(vehicle)
  }
  return total
}
