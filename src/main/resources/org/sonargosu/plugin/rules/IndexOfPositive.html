indexOf returns -1 when nothing is found, and 0 when the match is at the very start. Checking indexOf(x) > 0 therefore treats a match at the start as "not found". Use >= 0, or contains when the position doesn't matter.

Noncompliant code example

if (policyNumber.indexOf("AUTO") > 0) {   // false for "AUTO-12345"
  applyAutoRules(policyNumber)
}

Compliant solution

if (policyNumber.contains("AUTO")) {
  applyAutoRules(policyNumber)
}
