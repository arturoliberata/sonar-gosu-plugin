Two branches of an if chain or two cases of a switch with the same code are either a copy-paste mistake, or duplicated code that should be merged by combining the conditions.

Branches with a single statement are ignored, since repeating a short statement is often clearer than a complex combined condition.

Noncompliant code example

if (policy.Status == "draft") {
  validate(policy)
  save(policy)
} else if (policy.Status == "quoted") {
  validate(policy)
  save(policy)
} else {
  archive(policy)
}

Compliant solution

if (policy.Status == "draft" or policy.Status == "quoted") {
  validate(policy)
  save(policy)
} else {
  archive(policy)
}
