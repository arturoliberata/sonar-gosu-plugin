An empty catch block hides failures: the program carries on as if nothing happened, and nobody finds out why data is wrong later. Handle or log the exception, or add a comment explaining why ignoring it is safe.

Noncompliant code example

try {
  doSomething()
} catch (e : Exception) {
}

Compliant solution

try {
  doSomething()
} catch (e : Exception) {
  _logger.error("doSomething failed", e)
}
