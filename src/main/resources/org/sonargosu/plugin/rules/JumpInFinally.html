A return, throw, break or continue inside a finally block overrides whatever the try block was doing. An exception thrown in the try block is silently discarded, and a value it returned is replaced.

break and continue are fine when they belong to a loop or switch that is itself inside the finally block.

Noncompliant code example

function load() : int {
  try {
    return readValue()   // an exception here is lost
  } finally {
    return 0
  }
}

Compliant solution

function load() : int {
  try {
    return readValue()
  } finally {
    cleanUp()
  }
}
