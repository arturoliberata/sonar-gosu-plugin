Using the same expression on both sides of a comparison, logical, bitwise, subtraction, division or remainder operator is almost always a copy-paste mistake: a == a is always true, x - x is always zero, and ready and ready checks the same thing twice.

Expressions containing function calls are ignored, since calling a function twice can give different results.

Noncompliant code example

if (policy.StartDate == policy.StartDate) {   // meant policy.EndDate?
  renew(policy)
}

Compliant solution

if (policy.StartDate == policy.EndDate) {
  renew(policy)
}
