new BigDecimal(0.1) does not create 0.1. A double cannot represent 0.1 exactly, and the constructor keeps the binary rounding error: the result is 0.1000000000000000055511151231257827021181583404541015625. With money amounts and rates, those errors show up as off-by-a-cent results.

Use a string, BigDecimal.valueOf(...), or Gosu's bd literal suffix.

Noncompliant code example

var taxRate = new BigDecimal(0.07)

Compliant solution

var taxRate = 0.07bd
var otherRate = new BigDecimal("0.07")
var thirdRate = BigDecimal.valueOf(0.07)
