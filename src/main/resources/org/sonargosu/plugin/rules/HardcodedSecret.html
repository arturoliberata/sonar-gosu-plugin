API keys, access tokens and private keys written in the source code are visible to everyone with access to the code, its history and built artifacts. A leaked key must be revoked and replaced. Load secrets from a secure configuration or a vault instead.

This rule reports:

  • a long, random-looking string assigned to a name ending in secret, token, apiKey, accessKey, privateKey and similar;
  • any string with the format of a well-known credential: AWS access key ids, GitHub and Slack tokens, and private key blocks (-----BEGIN PRIVATE KEY-----).

Short or readable values, such as tokenHeader = "Authorization", are not reported.

Noncompliant code example

var ratingApiKey = "k3J9x7Qm2pL8vT4nR6wZ"

Compliant solution

var ratingApiKey = SecretStore.get("rating.api.key")
