Two nested if statements without an else are equivalent to a single if joining both conditions with and. Merging them removes a level of nesting and makes the code easier to read.

Noncompliant code example

if (policy != null) {
  if (policy.Status == "active") {
    renew(policy)
  }
}

Compliant solution

if (policy != null and policy.Status == "active") {
  renew(policy)
}
