In an if / else if chain, only the first matching condition runs. A condition that repeats an earlier one can never be true when it is evaluated, so its branch is dead code. This is usually a copy-paste mistake where another condition was intended.

Noncompliant code example

if (claim.Amount > 100000) {
  assignSenior(claim)
} else if (claim.Amount > 10000) {
  assignStandard(claim)
} else if (claim.Amount > 100000) {   // never true here
  escalate(claim)
}

Compliant solution

if (claim.Amount > 100000) {
  assignSenior(claim)
} else if (claim.Amount > 10000) {
  assignStandard(claim)
} else if (claim.Fraud) {
  escalate(claim)
}
