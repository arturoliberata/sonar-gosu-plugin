A private field that is never used anywhere in its file is dead code and should be removed.

In Gosu, fields are private unless declared public, protected or internal. A field exposed as a property with as (var _name : String as Name) is considered used.

Noncompliant code example

class RatingService {
  var _cache : Map<String, BigDecimal>   // never used

  function rate(policy : Policy) : BigDecimal {
    return compute(policy)
  }
}

Compliant solution

class RatingService {
  function rate(policy : Policy) : BigDecimal {
    return compute(policy)
  }
}
