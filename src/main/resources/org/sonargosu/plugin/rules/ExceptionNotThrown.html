Creating an exception without throw does nothing: the exception is discarded, and the program carries on as if the error had not happened. The throw keyword was almost certainly forgotten.

Noncompliant code example

if (policy.EffectiveDate == null) {
  new IllegalStateException("Policy has no effective date")
}

Compliant solution

if (policy.EffectiveDate == null) {
  throw new IllegalStateException("Policy has no effective date")
}
