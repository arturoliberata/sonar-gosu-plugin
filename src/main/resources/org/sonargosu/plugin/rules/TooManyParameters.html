A long parameter list usually means the function does too much, or that the parameters belong together in a class or structure. It also makes calls easy to get wrong, since arguments of the same type can be swapped without any error.

Noncompliant code example

function createClaim(policy : Policy, date : Date, amount : BigDecimal, city : String,
    state : String, zip : String, reporter : String, phone : String) : Claim

Compliant solution

function createClaim(policy : Policy, loss : LossDetails, reporter : Contact) : Claim
