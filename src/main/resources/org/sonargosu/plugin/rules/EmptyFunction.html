A function with an empty body looks unfinished. If doing nothing is intentional, for example an override that deliberately disables a behavior, say so in a comment inside the body. Otherwise, implement it or throw an UnsupportedOperationException.

Constructors are not reported: an empty private constructor is a common way to prevent instantiation.

Noncompliant code example

override function onRenewal(period : PolicyPeriod) {
}

Compliant solution

override function onRenewal(period : PolicyPeriod) {
  // Renewals need no extra processing for this product line
}
