When every branch of an if / else chain, every case of a switch with a default, or both sides of a ? : operator do the same thing, the condition makes no difference. Either the condition is useless, or one of the branches was meant to do something else.

Noncompliant code example

var fee = claim.Expedited ? 50bd : 50bd

if (policy.Renewal) {
  sendNotice(policy)
} else {
  sendNotice(policy)
}

Compliant solution

var fee = claim.Expedited ? 75bd : 50bd

sendNotice(policy)
