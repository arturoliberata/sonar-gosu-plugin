An empty block of code in an if, else, loop, try, finally or using statement is either missing code or dead weight. Fill it, remove it, or add a comment explaining why it is empty.

Empty catch blocks, function bodies and \ -> {} blocks are covered by other rules or are a normal idiom, and are not reported here.

Noncompliant code example

if (claim.Closed) {
} else {
  reopen(claim)
}

Compliant solution

if (not claim.Closed) {
  reopen(claim)
}
