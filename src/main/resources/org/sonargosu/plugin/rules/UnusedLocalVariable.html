A local variable that is declared but never used is dead code. It makes readers wonder what it was for, and often points at unfinished or broken logic.

Variables used only inside string templates, such as "Total: ${total}", count as used. Resource variables of a using statement are not reported, since using closes them.

Noncompliant code example

function premium(policy : Policy) : BigDecimal {
  var discount = policy.Discount   // never used
  return policy.BasePremium
}

Compliant solution

function premium(policy : Policy) : BigDecimal {
  return policy.BasePremium
}
