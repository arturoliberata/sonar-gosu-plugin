A private function that is never called from its file is dead code and should be removed. Keeping it makes the class harder to understand and to change.

Noncompliant code example

class ClaimHelper {
  function isLarge(claim : Claim) : boolean {
    return claim.Amount > 10000
  }

  private function legacyCheck(claim : Claim) : boolean {   // never called
    return claim.Amount > 5000
  }
}

Compliant solution

class ClaimHelper {
  function isLarge(claim : Claim) : boolean {
    return claim.Amount > 10000
  }
}
