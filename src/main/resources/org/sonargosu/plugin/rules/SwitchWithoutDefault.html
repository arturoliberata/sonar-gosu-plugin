A switch without a default case silently does nothing for values nobody thought of, including values added to a typelist or enum later. A default case makes the behavior explicit, even if it only logs or throws.

Noncompliant code example

switch (claim.State) {
  case "open":
    notifyAdjuster(claim)
    break
  case "closed":
    archive(claim)
    break
}

Compliant solution

switch (claim.State) {
  case "open":
    notifyAdjuster(claim)
    break
  case "closed":
    archive(claim)
    break
  default:
    throw new IllegalStateException("Unexpected state " + claim.State)
}
