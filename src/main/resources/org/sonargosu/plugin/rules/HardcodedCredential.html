A password written in the source code is visible to everyone with access to the code, its history, backups and built artifacts, and it cannot be changed without a new release. Load passwords from a secure configuration, a credential store or a vault instead.

This rule reports:

  • a string literal assigned to a name ending in password, passwd, pwd, passphrase or passcode (variables, fields, properties, named arguments, initializers and map entries);
  • password=... parameters inside strings, such as connection strings;
  • a password in a URL: https://user:password@host.

Labels containing spaces, property names such as "db.password", placeholders and masks such as "********" are not reported.

Noncompliant code example

var dbPassword = "Summer2024!"
var url = "jdbc:oracle:thin:@db:1521/claims;user=gw;password=Summer2024!"

Compliant solution

var dbPassword = CredentialStore.get("claims.db.password")
